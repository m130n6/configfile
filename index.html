Pengaturan Database Google Sheet

Hubungkan aplikasi ini dengan Google Sheet Anda secara gratis

Cara Menghubungkan ke Google Sheet:

  1. Buka Google Sheets dan buat Spreadsheet baru.
  2. Klik menu Ekstensi (Extensions) → Apps Script.
  3. Hapus kode yang ada, lalu tempelkan kode dari file Code.gs dan simpan.
  4. Klik tombol Terapkan (Deploy) → Deployment baru (New deployment).
  5. Pilih jenis Aplikasi Web (Web App).
  6. Atur Execute as: Me, dan Who has access: Anyone (Siapa saja), lalu klik Deploy.
  7. Salin Web App URL yang muncul ke kolom input paling bawah halaman saat berada di Mode Admin.
Berhasil disimpan!
